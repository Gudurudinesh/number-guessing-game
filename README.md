Number Guessing Game 🎯

About

A simple number guessing game built using Python. The player guesses a secret number and receives hints until the correct number is found.

Features

- Accepts user input
- Displays "Too high" or "Too low"
- Counts the number of attempts
- Shows a success message when the guess is correct

Technologies Used

- Python 3

How to Run

1. Install Python 3.
2. Download this repository.
3. Open PowerShell in the project folder.
4. Run:

py guessing.py

Concepts Learned

- User input
- Conditional statements
- Loops
- Basic problem-solving
